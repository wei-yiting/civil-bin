## 實際驗證的流程

- 照片上傳、尺寸人工登記、送出、店家收受／拒收、當日申報、市府查核與跨分頁同步。
- 拒收量不增加照片佐證量，停收會影響民眾交付，照片與查核資料重新載入後仍保留。
- Leaflet 地圖跨角色重新建立、鍵盤移動、縮放、模擬 GPS 與拒絕定位後的操作。
- 店家登錄、地圖選點、重新載入，以及民眾與市府端顯示新店家。
- 市府集合標記展開、申報量切換、行政區與公共清潔箱圖層篩選。
- 官方 CSV 解析、Big5 編碼、去重、異常座標排除、API 快取及錯誤處理。
- 真實本機 API 與瀏覽器皆取得官方 773 個唯一公共清潔箱位置；詳細來源與排除規則見 [公共清潔箱資料](public-bins.md)。位置數不等於實體箱體數量。
- 自動化測試以替代圖磚避免大量請求公共服務；另在互動瀏覽器確認真實 OpenStreetMap 圖磚載入與地圖呈現。
- JSON 匯出、重設、清運情境、過去日期與無資料情境；手機與桌機無頁面水平溢出。
- 未修改原版 HTML 的三端 HTTP 流程，以及新版單檔 HTML 的交付流程。

## 測試中處理的問題

- 手機的合作點標記曾被縮放控制遮住，調整預設縮放與搜尋後的可視範圍。
- 全區視角的相鄰店家標記重疊，改為集合標記，點選後展開。
- 改用 SVG 圖層並驗證跨角色卸載與建立地圖，不再出現 Canvas 生命週期錯誤。
- 測試時鐘改為隨時間前進，確保 Leaflet 動畫能完成。

## 範圍限制

- 原版「筆電打不開」尚未重現；詳見 [原版診斷紀錄](diagnosis.md)。未把工具禁止 `file://` 視為使用者的故障原因。
- 雙擊本機 HTML、實體手機相機授權、Safari／Firefox 與不同裝置同步未經本次驗證。
- 舊版體積、合作店家與清運政策數據是示範；新版尺寸件數為人工登記；公共清潔箱位置來自官方開放資料。
- 本機模式業務資料儲存在同一瀏覽器；Supabase 模式具備登入、權限、private 照片儲存與同步。實際雲端專案已填入 gitignored env，使用者已執行初始化 SQL 並啟用匿名登入，實際讀取 24 店／291 筆示範交付／62 筆日申報成功。店家與市府帳號已授權，三個獨立本機 origin 的完整雲端交付流程已實測；實體手機跨裝置仍待驗證。
- GitHub Pages 使用內嵌官方快照；Vite 開發伺服器與 Vercel API 可抓取官方來源。Vercel 正式部署尚未驗證。
